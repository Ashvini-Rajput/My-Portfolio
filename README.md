# My-Portfolio

Developed a responsive Personal Portfolio Website to showcase my technical skills, projects, education, training, certifications, and contact information. The website provides a professional platform to present my work, achievements, and experience as a Java Full Stack Developer.

The portfolio includes sections such as Home, About Me, Technical Skills, Projects, Education, Training, Certifications, Achievements, and Contact. It features a modern user interface, responsive design, smooth navigation, social media integration, and downloadable resume functionality.

Technologies Used
HTML5
CSS3
JavaScript
Font Awesome
GitHub Pages (for deployment)
